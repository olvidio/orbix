# Flujo - Gestionar E43

Visualización del certificado E43 (envío de información a otra región STGR).

## Objetivo De Usuario

Consultar el certificado E43 de un alumno en una actividad: datos personales, delegaciones de origen y destino, actividad, y las asignaturas matriculadas con sus notas.

## Punto De Entrada

Lista de asistentes de una actividad: botón **E43**.

## Fragmentos O Pantallas Auxiliares

- `actividadestudios.pantalla.e43`
- `frontend/asistentes/view/select_asistentes_a_una_actividad.phtml`

## Escenarios Inferidos

### Ver el certificado E43 de un alumno

Pasos propuestos:
1. En el dossier de asistentes de una actividad, seleccionar al alumno.
2. Pulsar **E43**.
3. Se muestra el certificado en pantalla, con un botón para imprimirlo en PDF.

Endpoints asociados:
- `/src/actividadestudios/e43_data`
