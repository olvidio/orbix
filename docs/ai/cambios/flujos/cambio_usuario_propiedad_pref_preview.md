# Ayuda IA - Previsualizar una condición

Usa este documento para responder preguntas de usuario sobre como trabajar con `Previsualizar una condición`.

## Cuando Usar Esta Ayuda

Responder con esta ayuda cuando el usuario pregunte por:
- Como previsualizar una condición en Previsualizar una condición?

## Donde Entrar

- Configurar aviso (`cambios.pantalla.usuario_avisos_pref`)

## Como Responder

Da pasos cortos y orientados a usuario. Si falta ruta de menu, dilo como pendiente de documentar.

## Previsualizar una condición

1. En la ventana de condición, pulsar guardar.
2. Se muestra el texto de la condición en la fila; no se guarda definitivamente hasta grabar todo.

Referencias tecnicas para verificar la respuesta:
- `/src/cambios/cambio_usuario_propiedad_pref_preview`

## Pantallas Y Fragmentos Relacionados

- `cambios.pantalla.usuario_avisos_pref`
- `cambios.pantalla.usuario_avisos_pref`

## Objetivo

Ver el texto de la condición y dejarla en la tabla sin guardar todavía en la base de datos.

## Limites De La Respuesta

- No inventar permisos si no estan documentados.
- No inventar rutas de menu si aparecen como pendientes.
- Si el usuario pregunta por errores concretos, responder que estan pendientes salvo que el catalogo los documente.
