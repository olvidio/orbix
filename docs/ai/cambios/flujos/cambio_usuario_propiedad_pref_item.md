# Ayuda IA - Poner condición a un campo

Usa este documento para responder preguntas de usuario sobre como trabajar con `Poner condición a un campo`.

## Cuando Usar Esta Ayuda

## Donde Entrar

## Como Responder

Da pasos cortos y orientados a usuario. Si falta ruta de menu, dilo como pendiente de documentar.

## Poner condición a un campo

1. En la tabla de campos, pulsar modificar en el campo.
2. Elegir el operador y el valor y el alcance, y guardar la condición.
